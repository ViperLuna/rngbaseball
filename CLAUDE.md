# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

rngbaseball — a baseball RNG game.

## Git workflow

- Develop changes on a branch and open a pull request as usual.
- Claude may merge its own pull requests once any CI checks pass, without
  waiting for manual approval first. Report what was merged after the fact.
- Still avoid force-pushes, history rewrites, or merging someone else's PR
  without being asked.
